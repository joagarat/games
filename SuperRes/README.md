# SUPER RES

Juego de microscopía de súper-resolución (DNA-PAINT / SMLM) del Departamento de Genómica, IIBCE.
Las moléculas "parpadean" de a una: tocá o hacé clic en el centro de cada localización para reconstruir la estructura.

- **Pantallas:** IIBCE Nanorulers y Poro Nuclear
- **Dificultad:** Medio, Difícil y Dr. Localizador (velocidad de parpadeo)
- **Puntaje:** suma de 10/distancia entre cada localización real y tu toque más cercano

Versión web (HTML + JavaScript) portada del proyecto original en Godot. Funciona en PC y en celular.

## Publicar con GitHub Pages

1. Subí todos los archivos de esta carpeta a la raíz del repositorio.
2. En el repositorio: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
3. El juego queda en `https://<usuario>.github.io/<repositorio>/`.

Los puntajes se guardan en el navegador de cada dispositivo (localStorage).

Música: "La Cumparsita".
