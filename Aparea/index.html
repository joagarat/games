Apareá las bases

A=T2 puentes H G≡C3 puentes H

Caen fragmentos de ADN de distintas formas. Cada base tiene que quedar arriba de su complementaria. Cuando una fila completa aparea con la de abajo, se cierra la doble hélice y las dos filas desaparecen.

Al principio se permiten hasta 4 mismatches por hélice. Cada 3 hélices subís de nivel: va más rápido y se permiten menos mismatches. Girá el fragmento para encontrar dónde encaja, y si no encaja en ningún lado, guardalo para después. Una vez por nivel podés usar dos enzimas: caen desde arriba y las ubicás como un fragmento más: la DNasa corta un bloque de 2×2 debajo de donde cae y la helicasa separa (borra) la fila sobre la que cae. La base N es un comodín: aparea con cualquiera.

En el celu: deslizá para mover, tocá para girar, deslizá rápido hacia abajo para soltar y hacia arriba para guardar.
